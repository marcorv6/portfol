# Portfolio Navigation Map

- `app/`: Next.js App Router pages:
  - `app/page.tsx`: Portfolio Homepage.
  - `app/about/page.tsx`: About Marco Romero & background.
  - `app/project/page.tsx`: Projects showcase.
  - `app/contact/page.tsx`: Contact form.
  - `app/blog/page.tsx`: Engineering blog listing page.
  - `app/blog/[slug]/page.tsx`: Individual blog article detail page.
- `content/posts.ts`: Blog posts database and content repository.
- `components/`: UI components (layout headers, footers, theme toggle, project cards).
