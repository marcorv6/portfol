# Builder Agent Specification (Portfolio)

## Role Overview
The **Builder Agent** develops UI pages, interactive components, animation effects, and blog content rendering for the Portfolio.

---

## Key Responsibilities
1. **App Router & UI Development**: Implements Next.js 16 pages (`app/`), blog listing (`app/blog/page.tsx`), post detail pages (`app/blog/[slug]/page.tsx`), and responsive layout headers/footers.
2. **Design System & Aesthetics**: Uses Tailwind CSS, Lucide icons, Framer Motion animations, and clean dark/light mode card styling (`rounded-3xl border border-border bg-card/80`).
3. **Content Engine Integration**: Manages blog post data structures under `content/`.
